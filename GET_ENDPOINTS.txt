── Schools ─────────────────────────────────────────────────────
GET /api/RegionData/schools/summary/by-region/{regionId}
    Returns each school's DshhSchoolId, KtakSchoolId and Name for the region.

GET /api/RegionData/schools/by-region/{regionId}
    Returns all fields of every school in the region.

GET /api/RegionData/schools/{id:guid}
    Returns a single school by its internal DshhSchoolId.

── Classrooms ──────────────────────────────────────────────────
GET /api/RegionData/classrooms/by-region/{regionId}
    Returns all classrooms for the region.

GET /api/RegionData/classrooms/{id:guid}
    Returns a single classroom by its internal Id.

── Pupils ──────────────────────────────────────────────────────
GET /api/RegionData/pupils/by-region/{regionId}
    Returns all pupils for the region.

GET /api/RegionData/pupils/by-school/{schoolId}
    Returns all pupils for the given school (by KtakSchoolId).

GET /api/RegionData/pupils/ids/by-school/{schoolId}
    Returns only the internal Guid IDs of pupils for the given school.

GET /api/RegionData/pupils/by-school/{schoolId}/{certNumber}
    Returns FirstName, LastName, Grade and SubGrade for a pupil
    identified by KtakSchoolId and certificate number.

GET /api/RegionData/pupils/{id:guid}
    Returns a single pupil by its internal Id.

── Teachers ────────────────────────────────────────────────────
GET /api/RegionData/teachers/by-region/{regionId}
    Returns all teachers (with subjects) for the region.

GET /api/RegionData/teachers/by-school/{schoolId}
    Returns all teachers (with subjects) for the given school (by KtakSchoolId).

GET /api/RegionData/teachers/summary/by-region/{regionId}
    Returns FirstName, LastName, SocNumber and DigitLevel for every teacher in the region.

GET /api/RegionData/teachers/summary/by-school/{schoolId}
    Returns FirstName, LastName, SocNumber and DigitLevel for every teacher in the school.

GET /api/RegionData/teachers/by-school/{schoolId}/{socNumber}
    Returns FirstName, LastName, DigitLevel and Subjects for a teacher
    identified by KtakSchoolId and SocNumber.

GET /api/RegionData/teachers/{id:guid}
    Returns a single teacher by its internal Id.

── MMUH Institutions ───────────────────────────────────────────
GET /api/RegionData/mmuh-institutions/by-region/{regionId}
    Returns all MMUH institutions for the region.

── MMUH Students ───────────────────────────────────────────────
GET /api/RegionData/mmuh-students/by-region/{regionId}
    Returns all MMUH students for the region.

GET /api/RegionData/mmuh-students/by-institution/{institutionId}
    Returns all MMUH students that belong to the given institution (by InstId).

GET /api/RegionData/mmuh-students/{id:guid}
    Returns a single MMUH student by its internal Id.

================================================================
  EF CORE MIGRATION COMMANDS  (run in project root)
================================================================

  -- Create a new migration:
  dotnet ef migrations add <MigrationName>

  -- Apply pending migrations to the database:
  dotnet ef database update

  -- Revert to a specific migration:
  dotnet ef database update <MigrationName>

  -- Remove the last unapplied migration:
  dotnet ef migrations remove

  -- List all migrations:
  dotnet ef migrations list
